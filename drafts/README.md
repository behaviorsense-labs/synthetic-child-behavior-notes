# V2 Batch Drafts

This folder is used for draft rows generated during the v2 expansion.

Draft rows should be reviewed and validated before being merged into the main v2 dataset file.

## Process

1. Generate rows using prompts in the `prompts/` folder.
2. Save draft rows by category.
3. Review rows for safety, privacy, originality, and consistency.
4. Fix or remove flagged rows.
5. Merge approved rows into `data/synthetic_child_behavior_notes_v2_1000.csv`.

## Status

Draft rows are not final until they are reviewed and merged.
