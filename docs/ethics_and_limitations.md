# Ethics and Limitations

This dataset is fully synthetic. It does not include real child, caregiver, school, therapy, patient, or clinical data.

## Why Synthetic Data?

Real child behavior notes can be sensitive and private. Synthetic examples allow people to test ideas, build prototypes, and run experiments without using real family or clinical information.

## What This Dataset Can Be Used For

This dataset may help with:

- testing ABC behavior note structure
- building caregiver-support prototypes
- experimenting with child behavior category classification
- creating therapy-session summary examples
- testing follow-up question generation
- teaching or learning about privacy-safe AI examples

## What This Dataset Should Not Be Used For

This dataset should not be used for:

- diagnosis
- treatment advice
- clinical decisions
- risk scoring
- labeling a child with a condition
- replacing therapists, teachers, doctors, or other professionals

## Important Limitation

The examples are synthetic. They may not fully match real family, school, therapy, or clinical situations.

The dataset is meant for research and educational prototyping only.

## Support Ideas

Some rows may include a general support idea. These are simple caregiver-support examples, not medical or therapy recommendations.

Families and caregivers should speak with qualified professionals for clinical, educational, or therapy decisions.

## Privacy

This dataset is meant to use only synthetic examples.

During dataset review, examples should be checked to make sure they do not include names, phone numbers, email addresses, home addresses, school names, clinic names, or other real personal details.

If any example looks too specific or realistic, it should be edited or removed before release.
