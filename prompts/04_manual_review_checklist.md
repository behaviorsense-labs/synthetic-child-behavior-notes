# Manual Review Checklist

Use this checklist when reviewing dataset rows before release.

## Row Review

- [ ] Row is synthetic.
- [ ] Row does not include real personal details.
- [ ] Row uses simple caregiver-style wording.
- [ ] Row does not include diagnosis or treatment language.
- [ ] Category matches the observation.
- [ ] Antecedent is what happened before the behavior.
- [ ] Behavior is observable.
- [ ] Consequence is supported by the observation.
- [ ] Support idea is general and not clinical advice.
- [ ] Follow-up question is parent-friendly.
- [ ] Difficulty level is reasonable.
- [ ] Ambiguity level is reasonable.
- [ ] Row does not sound copied from a public source.
- [ ] Row is not too similar to another row.
